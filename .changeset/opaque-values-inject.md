Add opt-in, run-scoped sensitive input with metadata-only SSE requests, a
bounded non-JSON client transport, one-use in-memory handles, and exact-object
trusted adapters. Managed browser injection binds the live origin, document,
target and structurally declared field, blocks ordinary typing into those
fields, and disables browser capture after a value crosses the boundary.
The first browser adapter is intentionally limited to an exclusively owned
root agent and a live ephemeral Gateway-managed Chrome profile; embedded,
persistent, helper-owned and messaging-channel contexts fail closed.
