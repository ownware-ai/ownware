Add capability-negotiated, content-free effect-reversal offers and immutable
execution receipts. The first supported inverse is intentionally limited to a
new pending memory proposal created by the exact root `remember` tool: execution
conditionally rejects that same revision in one durable transaction and remains
idempotent across restart. Same-name tools, helpers, external runtimes, changed
targets and arbitrary effects receive no generic undo path.
